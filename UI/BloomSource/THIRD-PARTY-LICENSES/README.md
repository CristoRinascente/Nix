# Terze parti

Onyx usa il pacchetto React [`thinking-orbs`](https://github.com/Jakubantalik/thinking-orbs) di Jakub Antalik, versione 0.3.1, per le animazioni dell’orb. È il motore originale a cui il progetto [Haplo ThinkingOrbs](https://github.com/haplollc/ThinkingOrbs), indicato come riferimento per queste animazioni, dichiara di essere fedele formula per formula.

Il componente viene incluso nella compilazione locale dell’interfaccia e non effettua richieste di rete durante l’esecuzione. La licenza MIT è in `ThinkingOrbs-MIT.txt`.
